Google Play Store Listing - Local Chat

App name:
Local Chat

Package name:
com.shady.localchat

Short description:
Simple local chat app for instant messaging between devices.

Long description:
Local Chat is a simple and fast chat application designed for instant messaging between devices. The current version works on the same local Wi-Fi network and allows users to send messages quickly between connected devices.

The app is designed as a starting point for a private chat platform that can later support secure accounts, private conversations, notifications, and voice or video calls.

Main features:
- Simple chat interface.
- Fast real-time messaging.
- Works between laptop and phone on the same local network.
- Clean interface under the name Local Chat.
- Supports future development for accounts and private chats.

Current development note:
This app is still under development and is not ready for public release until login security, online server hosting, database storage, and privacy requirements are completed.
